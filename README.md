# spectral-encryption-signals

Código-fonte desenvolvido para a dissertação de Mestrado em Engenharia Elétrica intitulada:

“Criptografia Espectral de Sinais Utilizando Codificação de Fase e Embaralhamento Espectral”

Este repositório tem como objetivo disponibilizar os códigos utilizados no desenvolvimento do trabalho, permitindo sua consulta, execução, teste e validação dos resultados apresentados na dissertação.

Requisitos

O projeto foi desenvolvido em Python.

As dependências necessárias para execução estão indicadas nos arquivos do repositório.

Uso

O código é disponibilizado para fins acadêmicos, educacionais e de pesquisa.

O uso comercial não é autorizado sem consentimento prévio do autor. Consulte o arquivo LICENSE para mais informações.
